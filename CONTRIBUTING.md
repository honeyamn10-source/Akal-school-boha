# Contributing to Akal School Boha

Thank you for your interest in contributing. By participating you agree to the [Code of Conduct](CODE_OF_CONDUCT.md).

## Important: client work

This repository contains client-owned branding, photos, and content for an Akal School client. **Do not** reuse, copy, or redistribute client materials without the client's permission, and never repurpose this repository as a saleable template.

## Getting started

1. Fork the repository and create a feature branch.
2. Keep changes focused — one logical change per pull request.
3. Test by previewing locally and verifying layout across browsers.
4. Verify form delivery with test data before claiming forms work.

## Pull request checklist

- Describe the **problem** and the **behaviour change**.
- Confirm no student data, personal details, or registration submissions are included.
- Preserve school branding and content as-is unless the client requested changes.

## Reporting bugs

- Include the browser and reproduction steps.
- Keep student details and registration submissions out of public issues.
